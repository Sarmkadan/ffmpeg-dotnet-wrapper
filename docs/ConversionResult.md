# ConversionResult

The `ConversionResult` class encapsulates the final outcome, metadata, and diagnostic information resulting from an FFmpeg conversion operation within the `ffmpeg-dotnet-wrapper` project. It provides structured access to the success status, output details, execution timing, and any metrics or errors encountered during the process.

## API

### Properties

*   **`Id`** (`string`)
    The unique identifier associated with the conversion job.
*   **`IsSuccess`** (`bool`)
    Indicates whether the conversion operation completed successfully.
*   **`OutputFilePath`** (`string?`)
    The full file path to the generated output media, or `null` if the conversion failed or produced no output file.
*   **`OutputMedia`** (`MediaFile?`)
    A `MediaFile` object representation of the successful output, or `null` if the conversion failed.
*   **`Duration`** (`TimeSpan`)
    The duration of the converted media file.
*   **`ErrorMessage`** (`string?`)
    Contains error details if the operation failed; `null` if the operation was successful.
*   **`WarningMessage`** (`string?`)
    Contains warning messages generated by the conversion process; `null` if no warnings occurred.
*   **`Metrics`** (`Dictionary<string, object>`)
    A dictionary storing arbitrary key-value pairs representing performance metrics or additional metadata for the conversion job.
*   **`CreatedAt`** (`DateTime`)
    The timestamp indicating when the conversion task was initialized.
*   **`CompletedAt`** (`DateTime`)
    The timestamp indicating when the conversion task finished processing.
*   **`FFmpegOutput`** (`string?`)
    The raw standard output and error stream captured from the FFmpeg process.

### Methods

*   **`GetElapsedTime()`** (`TimeSpan`)
    Calculates and returns the duration between `CreatedAt` and `CompletedAt`.
*   **`GetSizeReductionPercentage()`** (`double?`)
    Calculates the reduction in file size as a percentage. Returns `null` if the required metrics (input size/output size) are unavailable.
*   **`SetMetric(string key, object value)`** (`void`)
    Adds or updates a value within the `Metrics` dictionary.
*   **`GetMetric<T>(string key)`** (`T?`)
    Retrieves a value from the `Metrics` dictionary and casts it to the specified type `T`. Returns the default value of `T` if the key is not found or cannot be cast.
*   **`MarkAsSuccess()`** (`void`)
    Sets the `IsSuccess` status to `true` and updates `CompletedAt` to the current timestamp.
*   **`MarkAsFailed(string errorMessage)`** (`void`)
    Sets the `IsSuccess` status to `false`, updates `CompletedAt` to the current timestamp, and assigns the provided error message to `ErrorMessage`.
*   **`GenerateSummary()`** (`string`)
    Returns a formatted string summarizing the outcome of the conversion operation.

## Usage

### Handling Conversion Results
```csharp
var result = ffmpegWrapper.Convert(inputPath, outputPath);

if (result.IsSuccess)
{
    Console.WriteLine($"Conversion successful: {result.OutputFilePath}");
    Console.WriteLine($"Time taken: {result.GetElapsedTime().TotalSeconds} seconds");
}
else
{
    Console.WriteLine($"Conversion failed: {result.ErrorMessage}");
    Console.WriteLine($"Raw FFmpeg output: {result.FFmpegOutput}");
}
```

### Accessing Custom Metrics
```csharp
var result = ffmpegWrapper.Convert(inputPath, outputPath);

// Adding a custom metric after processing
result.SetMetric("EncoderPreset", "veryfast");

// Retrieving the metric
var preset = result.GetMetric<string>("EncoderPreset");
if (preset != null)
{
    Console.WriteLine($"Used encoder preset: {preset}");
}
```

## Notes

*   **Thread Safety:** The `ConversionResult` class is not inherently thread-safe. Concurrent access to the `Metrics` dictionary or modification of properties (e.g., via `SetMetric` or `MarkAsSuccess`) from multiple threads requires external synchronization.
*   **Nullability:** Always verify `OutputFilePath` and `OutputMedia` for null values before accessing them, particularly if `IsSuccess` is `false`.
*   **Metric Retrieval:** When using `GetMetric<T>`, ensure the requested type `T` matches the actual type stored in the dictionary to avoid unexpected results or casting exceptions.

# StreamingPipelineOptions

Configuration holder for a streaming pipeline that defines global behavior, default encoding parameters, and resource limits used when creating `StreamingPipeline` instances.

## API

### Enabled
**Purpose**  
Gets or sets a value indicating whether the pipeline is active. When `true` the pipeline processes media; when `false` it is idle.

**Type**  
`bool`

**Default**  
`false`

**Exceptions**  
- `ObjectDisposedException` – if the underlying pipeline has been disposed.

### DefaultSegmentDurationSeconds
**Purpose**  
Specifies the target duration (in seconds) of each media segment when the pipeline generates segmented output (e.g., HLS/DASH).

**Type**  
`int`

**Constraints**  
Must be greater than zero.

**Exceptions**  
- `ArgumentOutOfRangeException` – if the value is less than or equal to zero.

### DefaultPlaylistWindowSize
**Purpose**  
Defines the number of segments kept in the playback window (playlist) for live streaming.

**Type**  
`int`

**Constraints**  
Must be greater than zero and typically not less than `DefaultSegmentDurationSeconds`.

**Exceptions**  
- `ArgumentOutOfRangeException` – if the value is less than or equal to zero.

### DefaultFormat
**Purpose**  
Gets or sets the default container/streaming format (e.g., HLS, DASH, CMAF) used when no explicit format is supplied.

**Type**  
`StreamingFormat`

**Exceptions**  
None – the enum is closed; any value is valid.

### DefaultEncodeProfilesConcurrently
**Purpose**  
Indicates whether the pipeline should encode all rendition profiles in parallel or sequentially.

**Type**  
`bool`

**Default**  
`false`

**Exceptions**  
None.

### MaxConcurrentPipelines
**Purpose**  
Maximum number of pipelines that may run simultaneously within the owning process.

**Type**  
`int`

**Constraints**  
Must be at least one.

**Exceptions**  
- `ArgumentOutOfRangeException` – if the value is less than one.

### MaxConcurrentRenditionsPerPipeline
**Purpose**  
Maximum number of rendition encodings that a single pipeline may execute concurrently.

**Type**  
`int`

**Constraints**  
Must be at least one.

**Exceptions**  
- `ArgumentOutOfRangeException` – if the value is less than one.

### DowngradeSpeedThreshold
**Purpose**  
Threshold (as a fraction of real‑time) below which the encoder will automatically downgrade to a lower bitrate rendition to keep up with incoming data.

**Type**  
`double`

**Constraints**  
Must be non‑negative; values greater than 1 are allowed but treated as “always downgrade”.

**Exceptions**  
- `ArgumentOutOfRangeException` – if the value is negative.

### UpgradeSpeedThreshold
**Purpose**  
Threshold (as a fraction of real‑time) above which the encoder will consider upgrading to a higher bitrate rendition.

**Type**  
`double`

**Constraints**  
Must be non‑negative; typically set higher than `DowngradeSpeedThreshold`.

**Exceptions**  
- `ArgumentOutOfRangeException` – if the value is negative.

### BitrateDecisionWindowSegments
**Purpose**  
Number of recent segments examined when deciding whether to change bitrate renditions.

**Type**  
`int`

**Constraints**  
Must be at least one.

**Exceptions**  
- `ArgumentOutOfRangeException` – if the value is less than one.

### DefaultOutputBaseDirectory
**Purpose**  
Base directory where segment files and playlists are written. If `null` or empty, the process’ current working directory is used.

**Type**  
`string?`

**Exceptions**  
- `IOException` – if a non‑null value is supplied and the directory does not exist or is inaccessible.

### DefaultEnableHardwareAcceleration
**Purpose**  
When `true`, the pipeline attempts to use hardware‑accelerated codecs (e.g., NVENC, Quick Sync) where available.

**Type**  
`bool`

**Default**  
`false`

**Exceptions**  
None.

### DefaultProfiles
**Purpose**  
Collection of encoding profiles (resolution, bitrate, codec, etc.) that are applied by default to each rendition generated by the pipeline.

**Type**  
`IList<StreamingProfileOptions>`

**Constraints**  
The list must not be `null`; individual elements must not be `null`.

**Exceptions**  
- `ArgumentNullException` – if the list itself is `null`.  
- `ArgumentException` – if any element in the list is `null`.

### Name
**Purpose**  
User‑friendly identifier for the pipeline; used in logging and diagnostics.

**Type**  
`string`

**Constraints**  
Must not be `null`, empty, or consist only of whitespace.

**Exceptions**  
- `ArgumentException` – if the value is invalid.

### Width
**Purpose**  
Default video width (in pixels) applied when a profile does not explicitly specify a resolution.

**Type**  
`int`

**Constraints**  
Must be greater than zero.

**Exceptions**  
- `ArgumentOutOfRangeException` – if the value is less than or equal to zero.

### Height
**Purpose**  
Default video height (in pixels) applied when a profile does not explicitly specify a resolution.

**Type**  
`int`

**Constraints**  
Must be greater than zero.

**Exceptions**  
- `ArgumentOutOfRangeException` – if the value is less than or equal to zero.

### VideoBitrateKbps
**Purpose**  
Default target video bitrate (kilobits per second). A value of zero disables video encoding.

**Type**  
`int`

**Constraints**  
Must be zero or positive.

**Exceptions**  
- `ArgumentOutOfRangeException` – if the value is negative.

### AudioBitrateKbps
**Purpose**  
Default target audio bitrate (kilobits per second). A value of zero disables audio encoding.

**Type**  
`int`

**Constraints**  
Must be zero or positive.

**Exceptions**  
- `ArgumentOutOfRangeException` – if the value is negative.

### FrameRate
**Purpose**  
Default video frame rate (frames per second). Used when a profile does not specify its own frame rate.

**Type**  
`double`

**Constraints**  
Must be greater than zero.

**Exceptions**  
- `ArgumentOutOfRangeException` – if the value is less than or equal to zero.

### ToProfile
**Purpose**  
Read‑only property that constructs a `StreamingProfile` instance from the current option values. Useful for quickly creating a single‑rendition profile based on the pipeline’s defaults.

**Type**  
`StreamingProfile` (get‑only)

**Exceptions**  
- `InvalidOperationException` – if required fields such as `Width`, `Height`, `VideoBitrateKbps`, or `FrameRate` have invalid values (e.g., zero or negative) that prevent profile creation.

## Usage

### Example 1: Basic pipeline setup
```csharp
var options = new StreamingPipelineOptions
{
    Enabled = true,
    Name = "LiveHLS",
    Width = 1280,
    Height = 720,
    VideoBitrateKbps = 4500,
    AudioBitrateKbps = 128,
    FrameRate = 30.0,
    DefaultSegmentDurationSeconds = 2,
    DefaultPlaylistWindowSize = 5,
    DefaultFormat = StreamingFormat.Hls,
    DefaultEnableHardwareAcceleration = true,
    MaxConcurrentPipelines = 2,
    MaxConcurrentRenditionsPerPipeline = 4
};

// Add a couple of rendition profiles
options.DefaultProfiles = new List<StreamingProfileOptions>
{
    new StreamingProfileOptions { Width = 1280, Height = 720, VideoBitrateKbps = 4500 },
    new StreamingProfileOptions { Width = 854,  Height = 480,  VideoBitrateKbps = 2500 }
};

var pipeline = new StreamingPipeline(options);
pipeline.Start();
```

### Example 2: Using `ToProfile` for a quick single‑rendition profile
```csharp
var opts = new StreamingPipelineOptions
{
    Width = 1920,
    Height = 1080,
    VideoBitrateKbps = 8000,
    AudioBitrateKbps = 192,
    FrameRate = 60.0
};

StreamingProfile profile = opts.ToProfile; // returns a profile with the above settings
var singlePipe = new StreamingPipeline(new StreamingPipelineOptions { Enabled = true, DefaultProfiles = new List<StreamingProfileOptions> { profile } });
singlePipe.Start();
```

## Notes
- The class is **mutable** and not thread‑safe. Concurrent reads and writes to any property may result in undefined behavior. Configure the instance before passing it to a `StreamingPipeline` and treat it as immutable thereafter, or synchronize access externally.
- Setting `Enabled` to `false` while the pipeline is actively processing will cause the pipeline to stop after the current segment finishes; setting it to `true` restarts processing from the next segment.
- Changing `DefaultProfiles` after the pipeline has started does not affect already‑running renditions; new renditions will use the updated list.
- `DefaultOutputBaseDirectory` is only consulted when the pipeline creates its output folder; if the directory is removed while the pipeline runs, subsequent segment writes may throw `IOException`.
- The thresholds `DowngradeSpeedThreshold` and `UpgradeSpeedThreshold` are interpreted as ratios of real‑time processing speed; values outside the typical `[0, 2]` range are accepted but may produce unintuitive bitrate‑switching behavior.
- All integral properties that represent quantities (durations, counts, sizes, bitrates) reject non‑positive values via `ArgumentOutOfRangeException`; callers should validate input before assignment to avoid exceptions during pipeline initialization.

# Contributing to FFmpeg .NET Wrapper

Thank you for contributing! We welcome bug reports, feature requests, and pull requests.

## Guidelines

1. **Fork** the repository and create a feature branch: `git checkout -b feature/my-feature`
2. **Commit** changes with clear messages.
3. **Push** to your branch and open a pull request.
4. **Follow C# conventions**: Use PascalCase for public members, add XML documentation, and maintain formatting.
5. **Testing**: Run tests with `dotnet test` before submitting.

## Development

- **Build**: `dotnet build`
- **Test**: `dotnet test`
- **Documentation**: Add XML comments for all public classes and methods.
